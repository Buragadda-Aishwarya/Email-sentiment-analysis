# Email Sentiment Analysis System

## 📌 Project Description

This project is a web-based application that performs sentiment analysis on email data. It allows users to analyze both single and multiple emails to determine the emotional tone of the content.

## ⚙️ Technologies Used

* Python
* Django Framework
* MySQL Database
* VADER Sentiment Analysis

## 🚀 Features

* User Signup and Login
* Single Email Sentiment Analysis
* Multiple Email Sentiment Analysis
* Displays sentiment categories such as Positive, Negative, Neutral, Happy, and Extremely Happy

## ▶️ How to Run the Project

1. Install Python and Django
2. Navigate to project folder
3. Run the command:
   python manage.py runserver
4. Open browser and go to:
   http://127.0.0.1:8000/

## 📊 Output

The system analyzes email content and displays the predicted sentiment.
